Concurrency - Concurrency is the ability of a program to manage multiple tasks by making progress on more than one task during overlapping periods of time. Tasks may take turns executing rather than running simultaneously.

1. threading.Thread
2. asyncio

Parallelism - Parallelism is the ability to execute multiple tasks at exactly the same time using multiple CPU cores or processors.

1. multiprocessing.Process
2. concurrent.futures.ProcessPoolExecutor
